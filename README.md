🎓 LINKEDIF


Uma rede social profissional desenvolvida como projeto acadêmico no IFSP Araraquara, inspirada no LinkedIn e adaptada para o contexto educacional do instituto.




📋 Sobre o Projeto

O LINKEDIF é uma plataforma web desenvolvida durante as aulas no Instituto Federal de São Paulo — Campus Araraquara. O objetivo é simular e adaptar as funcionalidades de uma rede social profissional como o LinkedIn, voltada para estudantes, professores e egressos do IFSP.

O projeto foi construído de forma incremental ao longo das aulas, aplicando na prática os conceitos de desenvolvimento web.
